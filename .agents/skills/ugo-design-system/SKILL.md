# UGO UX / Design System

## Objetivo
Evitar divergencia visual y de interacción mientras crece el ecosistema UGO.

## Reglas
- Buscar y reutilizar tokens/componentes existentes antes de crear nuevos.
- Mantener una única intención por componente compartido.
- Respetar jerarquía, contraste, legibilidad, áreas táctiles y responsive.
- Diseñar estados loading, vacío, error, éxito, hover/focus y disabled cuando apliquen.
- Evitar CSS puntual que contradiga el sistema global.
- Mantener lenguaje y comportamiento coherentes entre roles sin forzar interfaces idénticas cuando las necesidades sean distintas.
- Verificar accesibilidad básica y navegación por teclado en web.

## Validación
Comparar visualmente con referencias/MD maestros y probar breakpoints/journeys afectados. Cualquier excepción al sistema debe quedar justificada.
