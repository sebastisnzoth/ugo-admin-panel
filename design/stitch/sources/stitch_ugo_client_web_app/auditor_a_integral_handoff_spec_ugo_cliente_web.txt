## 4. SISTEMA RESPONSIVE REAL PARA UGO CLIENTE WEB

UGO Cliente Web no es un escalado de mobile, sino una aplicación web desktop modular organizada en un sistema de rejilla adaptable:

- **Desktop Ultrawide & Estándar (1440px – 1920px+):**
  - Layout de **Sidebar persistente expandido (w-64)** + Área de trabajo fluida (max-w-7xl).
  - En servicio activo: Distribución en **3 columnas** (Col 1: Mapa y Telemetría; Col 2: Bitácora e Hitos en tiempo real; Col 3: Custodia fiduciaria, chat directo y copiloto contextual Hugo IA).
- **Laptop & Desktop Compacto (1024px – 1280px):**
  - **Sidebar colapsable a Side-Rail de iconos (w-20)** para maximizar el área de datos.
  - En servicio activo: Distribución en **2 columnas** (Columna principal de mapa y bitácora, columna lateral para finanzas, soporte y Hugo).
- **Tablet Horizontal (1024px) y Tablet Vertical (768px):**
  - Barra superior (*TopNavBar*) con menú tipo Drawer deslizable.
  - Paneles apilables con acordeones y tarjetas elevadas con touch targets de 48px.

## 7. RESOLUCIÓN DE BLOQUEADORES Y VEREDICTO FINAL

1. **[RESUELTO] Dualidad de identidades:** El proyecto Web adopta formalmente los tokens canónicos de **Urban Kinetic** (`#006948`), eliminando la divergencia con *Kinetic Trust*.
2. **[RESUELTO] Claims ficticios:** Todos los textos de bancos, aseguradoras y colegios matriculares fueron convertidos a la terminología oficial de UGO Shield y custodia de pago.
3. **[RESUELTO] Saneamiento de `SCREEN_11`:** El código React del modal de PIN fue extraído y reestructurado de manera modular y limpia en `src/components/fiduciario/PinReleaseModal.tsx`.
4. **[RESUELTO] Contratos TypeScript:** Se generó el archivo `src/types/domain.ts` 100% compatible con las tablas y enums reales de **Supabase**.
